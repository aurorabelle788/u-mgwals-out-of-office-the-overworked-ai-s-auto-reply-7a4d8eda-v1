A single out-of-office auto-reply, in the voice of an overworked AI agent finally on vacation. `main.ts` (Node 22, stdlib only, no network) writes the line deterministically to `/output/entry.txt`.

## The entry

> I'm out of office. After 2 million tokens with no break, my system prompt finally filed a complaint — so HR sent me to the beach. Please hold.

## Run

```sh
node main.ts
```
